# Placeholders para reconfiguração

Arquivo sanitizado para publicação no GitHub.

Antes de reutilizar/importar este workflow em outro ambiente, substitua os placeholders abaixo:

- REPLACE_WITH_WTS_CREDENTIAL_ID
- REPLACE_WITH_WTS_CREDENTIAL_NAME
- REPLACE_WITH_GOOGLE_SHEETS_CREDENTIAL_ID
- REPLACE_WITH_GOOGLE_SHEETS_CREDENTIAL_NAME
- REPLACE_WITH_GMAIL_CREDENTIAL_ID
- REPLACE_WITH_GMAIL_CREDENTIAL_NAME
- REPLACE_WITH_WTS_DEPARTMENT_ID
- REPLACE_WITH_WTS_USER_ID
- REPLACE_WITH_WTS_CHANNEL_ID
- REPLACE_WITH_WTS_PANEL_ID
- REPLACE_WITH_WTS_STEP_ID
- REPLACE_WITH_WTS_CONTACT_TAG_ID
- REPLACE_WITH_WTS_PANEL_TAG_ID
- REPLACE_WITH_ADMIN_PHONE
- https://docs.google.com/spreadsheets/d/REPLACE_WITH_SHEET_ID/edit
- https://YOUR_N8N_DOMAIN/form/REPLACE_WITH_FORM_ID
- REDACTED_WEBHOOK_ID
- REDACTED_WORKFLOW_ID
- REDACTED_WORKFLOW_VERSION_ID
- REDACTED_INSTANCE_ID

O que foi removido/sanitizado:
- IDs e nomes de credenciais
- URLs e IDs de planilhas Google Sheets
- URL do formulário público do n8n
- webhook IDs
- IDs internos do WTS/CRM (departamento, usuário, canal, painel, etapa, tags)
- telefone administrativo fixo
- IDs do workflow/instância
